# Card Backgrounds V1

This review package contains the generated bitmap assets used for the card-background pass.

## Integrated App Assets

- `assets/images/timer-challenge-bg.png` - timer challenge modal background.
- `assets/images/parent-check-bg.png` - parent confirmation modal background.
- `assets/images/task-success-bg.png` - success modal background.
- `assets/images/routine-homework-soft.png` - homework/school routine card art.
- `assets/images/routine-sport-soft.png` - sport routine card art.
- `assets/images/routine-cleanup-soft.png` - cleanup/household routine card art.
- `assets/images/routine-hygiene-soft.png` - hygiene routine card art.
- `assets/images/routine-weekend-soft.png` - weekend/creative routine card art.
- `assets/images/routine-meals-soft.png` - meals routine card art.
- `assets/images/routine-special-soft.png` - special/packing/birthday routine card art.

## Review Sheets

- `contact-sheets/generated-assets-review.png` - raw generated outputs.
- `contact-sheets/final-card-assets.png` - final resized app assets.

## Notes

- Modal backgrounds are `900x1200` RGB PNGs.
- Routine art is `512x512` RGBA PNG with transparent corners.
- Source generated images remain copied under `source/`; chroma-key alpha intermediates remain under `routine-art/`.
